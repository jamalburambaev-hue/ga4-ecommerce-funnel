# Воронка конверсии интернет-магазина: GA4 + BigQuery

**Ключевой вывод:** Самая большая потеря в воронке происходит на шаге `add_to_cart -> begin_checkout` (конверсия 19.7%). На мобильных устройствах (40% трафика) этот шаг составляет 39.59%. Предложены 3 гипотезы с потенциалом +1200 покупок.

## Контекст и вопросы
Анализ поведения пользователей интернет-магазина Google Merchandise Store.
Отвечаю на вопросы: где теряем покупателей, чем отличаются устройства и каналы, сколько денег приносит пользователь, что улучшать в первую очередь.

## Данные
- Источник: `bigquery-public-data.ga4_obfuscated_sample_ecommerce.events_*`
- Период: 01.11.2020 - 31.01.2021 (92 дня)
- Событий: 4 295 584. Пользователей: 270 154. Сессий: 360 129.
- Данные обфусцированы, метрики не равны реальным метрикам магазина.

## Методология
- Единица воронки: сессия (`user_pseudo_id + ga_session_id`).
- Шаги: session -> view_item -> add_to_cart -> begin_checkout -> purchase.
- Воронка каскадная (сессия дошла до шага N, только если прошла все предыдущие).
- Канал: `traffic_source.medium` (первое касание пользователя).
- Минимальный размер сегмента: 1000 сессий.

## Результаты

### Общая воронка
Самая низкая конверсия на шаге `add_to_cart -> begin_checkout` (19.7%).

### По устройствам
Mobile (143 тыс. сессий) конвертирует чуть лучше desktop (0.82% против 0.77%), но на шаге `cart -> checkout` отставание минимально (39.59% против 39.01%).

### По каналам
Лучший канал по конверсии — `(data deleted)` (1.76%), по выручке — `organic` ($104 007). Самый слабый — `cpc` (ARPU $0.58).

### Выручка, ARPU, AOV
Лучший ARPU и средний чек у `referral` ($1.51 и $136.03). Худший AOV у `cpc` ($98.43).

## Рекомендации (Гипотезы)
1. **Упрощение корзины (Mobile):** Потенциал +502 покупки (+$65 257).
2. **Гостевое оформление (Desktop):** Потенциал +732 покупки (+$95 166).
3. **Оптимизация рекламы (CPC):** Потенциал +15 покупок (+$1 476).

## Ограничения
- Данные обфусцированы и охватывают только 3 месяца (включая праздничный сезон).
- Канал = первое касание, а не источник конкретной сессии.
- Воронка каскадная, порядок событий внутри сессии не проверяется.
- Нет данных о марже, возвратах и стоимости привлечения (нельзя посчитать ROI).
